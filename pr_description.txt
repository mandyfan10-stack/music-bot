🚨 Severity: CRITICAL
💡 Vulnerability: User-controlled variables (`pendingReviewDelete` and `releaseToDelete`) were directly interpolated into URL paths for DELETE API requests without any sanitization or encoding.
🎯 Impact: This could potentially allow path traversal attacks (e.g., if an ID contained `../`) or manipulation of the API endpoint structure, leading to unauthorized actions or accessing unintended resources on the backend server.
🔧 Fix: Wrapped the path parameter variables in `encodeURIComponent()` when constructing the API fetch URLs to ensure any special characters are safely URL-encoded.
✅ Verification: Ensure the test suite passes (`node --test tests/utils.test.js`) and review the code changes to confirm `encodeURIComponent` is used in both `executeDeleteReview` and `executeDeleteRelease` fetch requests.

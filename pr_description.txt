🚨 Severity: HIGH
💡 Vulnerability: API routes were constructed by directly interpolating variables (`pendingReviewDelete` and `releaseToDelete`) into the URL path for HTTP DELETE requests. This can be exploited to bypass the intended path structure if the input contains path traversal characters like `../`.
🎯 Impact: While the backend might be secure against this, passing unsanitized variables into fetch URLs presents an injection vulnerability surface, leading to potential path traversal attacks (e.g. deleting arbitrary resources or interacting with unexpected endpoints).
🔧 Fix: Wrapped the path parameters with `encodeURIComponent()` to ensure all input is treated as a URI component and slashes or dots are properly encoded.
✅ Verification: Tested the utility module and successfully verified there are no syntax errors within the script logic, keeping all other features completely functional.

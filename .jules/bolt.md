## 2024-05-03 - Avoid Intermediate Array Copy and Sort Allocation
**Learning:** In Javascript, doing `let filtered = [...releases]; filtered = filtered.filter(x => ...);` allocates an entire copy of `releases` only for it to be immediately discarded and overwritten by `filter` (which itself returns a new array). Also, inside `sort` comparators, allocating empty fallback arrays via `(map.get(id) || []).length` occurs `O(N log N)` times, creating unnecessary garbage collection pressure.
**Action:** When filtering a source array conditionally, declare `let filtered;` and assign `filtered = source.filter(...)` if the filter is active, otherwise fallback to `filtered = [...source]`. For defensive length checks inside tight loops or `sort` comparators, use optional chaining `map.get(id)?.length || 0` instead of `(map.get(id) || []).length`.
